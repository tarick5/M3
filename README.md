## Exercícios realizados

### ex01 — Painel interativo

Página que recebe o nome do utilizador e atualiza uma mensagem de boas-vindas através do DOM. Inclui também um botão para alternar o tema visual, demonstrando eventos, alteração de texto, atributos ARIA e manipulação de classes CSS.

### ex02 — Lista de tarefas

Aplicação para criar, concluir e eliminar tarefas. Os itens são criados dinamicamente com JavaScript e o contador é atualizado a cada alteração. O exercício trabalha formulários, validação, delegação de eventos e criação de elementos no DOM.

### ex03 — Quiz de JavaScript e DOM

Quiz de três perguntas, gerado a partir de uma estrutura de dados em JavaScript. O utilizador escolhe as respostas, avança pelas perguntas e recebe a pontuação final. Foram usados arrays, funções, eventos e atualização dinâmica da interface.

## Como visualizar

Cada exercício é autónomo. Abra o ficheiro `index.html` dentro da pasta correspondente (`ex01`, `ex02` ou `ex03`) num navegador web.
